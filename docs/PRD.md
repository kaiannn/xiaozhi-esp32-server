# Desk Mate — 产品需求（PRD 草案）

> 基于 fork：`kaiannn/xiaozhi-esp32-server`（上游 `xinnan-tech/xiaozhi-esp32-server`）  
> 设备：Waveshare ESP32-S3-ePaper-1.54 **V2**  
> 定位：墨水屏语音练伴（英语口语/听力/背词）+ 家居语音中控  
> 状态：需求整理，供拆 Issue；**未排期实现**

---

## 1. 产品一句话

桌面小设备：用嘴练英语、用眼看单词与状态、用一句话开灯/切场景；大脑可私有部署（本仓库），设备可接官方小智固件或自研桥接。

## 2. 目标用户与场景

| 场景 | 用户故事 |
|------|----------|
| 口语 | 我按下说话，AI 扮演店员/考官陪我练，结束给我一行可改的英文建议 |
| 听力 | 设备读英文，我复述或选题，不靠字幕也能练 |
| 背词 | 早上屏上出现今日待复习；说对/选对则间隔变长 |
| 家居 | 「关书房灯」在 2s 内生效，屏上显示 OK/FAIL |
| 状态屏 | 低功耗常显：时间、温湿度、3 个灯、今日词汇进度 |

## 3. 非目标（本阶段明确不做）

- 端侧跑大模型 / 端侧严肃音素级发音评分（可后续接云评分）
- 完整多页智能家居看板（墨水屏只做摘要）
- 取代 Home Assistant 的规则引擎
- 全双工回声消除（MVP 用 PTT 半双工）

## 4. 架构原则

```
ESP32-S3 ePaper 固件 ──WS/MQTT──► 本 Server ──► ASR / LLM / TTS / 工具
                                      │
                                      ├─ English Tutor 会话与状态
                                      ├─ SRS 词库
                                      └─ Home 意图与 HA/MQTT 插件
```

- **产品逻辑优先落在本 Server**（可插件化、可迭代）
- 固件只保证：麦/喇叭/键/墨水屏状态协议/配网
- 与官方 xiaozhi.me 可并存：自定义模式走私有 Server

## 5. 模块需求

### M1 底座（依赖）

| ID | 需求 | MVP AC | 优先级 |
|----|------|--------|--------|
| B1 | 设备接入本 Server | 指定固件注册后能稳定上、下行 | P0 |
| B2 | 模式路由 | `tutor` / `vocab` / `home` / `chat` 可切换 | P0 |
| B3 | 屏幕指令协议 | Server 可下发行级文本、卡片、进度、OK/FAIL | P0 |
| B4 | 会话超时与打断 | 超时回待机；新 PTT 可打断旧 TTS | P1 |
| B5 | 配置与密钥 | 模型 key 不进设备固件；环境变量/控制台 | P0 |

### M2 英语口语 Tutor

| ID | 需求 | MVP AC | 优先级 |
|----|------|--------|--------|
| E1 | PTT 对讲 | 识别结果先上屏，再播回复 | P0 |
| E2 | 场景角色 | 至少：日常闲聊、点单、面试（B1）3 套 prompt | P0 |
| E3 | 单行纠错 | 每轮结束：1 条主要问题 + Better sentence；屏显+可读 | P0 |
| E4 | 评分摘要 | 流利度/准确度各 0–100 粗评（表达级，非音素级） | P1 |
| E5 | 可调语速/难度 | 0.8×/1.0×；CEFR A2–B2 标签 | P1 |
| E6 | 跟读（可选） | 播目标句→用户读→转写对照 | P2 |
| E7 | 每日 5 分钟模式 | 计时+今日轮次；结束简报上屏 | P1 |

### M3 听力

| ID | 需求 | MVP AC | 优先级 |
|----|------|--------|--------|
| L1 | 播句+选择题 | 播 1–2 句；A/B/C 按键选；判对错 | P1 |
| L2 | 复述判分 | 复述后 ASR 与原文相似度粗判 | P2 |
| L3 | 语速与重播 | 同句可重播；可 0.8× | P1 |

### M4 背单词 SRS

| ID | 需求 | MVP AC | 优先级 |
|----|------|--------|--------|
| V1 | 词库导入 | CSV/JSON；字段：词/音标/义/例句 | P0 |
| V2 | SRS 算法 | FSRS 或简化 SM-2；状态存 Server | P0 |
| V3 | 抽查 | 中→英 / 英→中 / 空耳例句；语音或按键 | P0 |
| V4 | 词库无关 | 支持多 deck（四级/雅思等） | P1 |
| V5 | 进度同步屏 | Server 推「今日 due N」到设备 | P1 |
| V6 | 复习报告 | 周正确率；导出可选 | P2 |

### M5 家居中控（后端未锁死时先做抽象层）

| ID | 需求 | MVP AC | 优先级 |
|----|------|--------|--------|
| H1 | 意图→动作 | 「开/关 + 灯/房间名」映射到 provider | P1 |
| H2 | Provider 抽象 | 先支持：MQTT 遥控器 + Home Assistant REST；米家后续 | P1 |
| H3 | 结果回显 | 屏显原句 + OK/FAIL；失败带原因短码 | P1 |
| H4 | 场景一句话 | 命名场景「阅读/睡眠/观影」映射多动作 | P1 |
| H5 | 设备状态订阅 | 灯状态变化可刷新屏（事件或轮询） | P1 |
| H6 | 快捷场景 API | LAN `POST /scene/xxx` 供手机/电脑调用 | P2 |
| H7 | 安全 | token 仅环境变量；默认鉴权 | P0 |

### M6 设备协同（固件侧为主，Server 定义协议）

| ID | 需求 | MVP AC | 优先级 |
|----|------|--------|--------|
| D1 | ePaper 卡片协议 | 标题/两行正文/页脚；全刷标记 | P0 |
| D2 | 模式图标 | 屏角显示 T/V/H/C | P1 |
| D3 | 深睡协同 | Server 可标注「可睡」/「保持唤醒」指令 | P2 |
| D4 | 板载按键语义 | BOOT=PTT；PWR=菜单/模式；长按=模式环 | P1 |
| D5 | 温湿度上云 | SHTC3 可选上报，进状态屏 | P2 |

## 7. 技术选型备忘

| 项 | 倾向 | 说明 |
|----|------|------|
| 设备固件 | 小智官方/微雪适配 V2 或自有 prototype | 板级 ePaper 以固件仓 issue 为准 |
| Server | 本 fork | 插件/工具按上游结构扩展 |
| ASR/LLM/TTS | 可配置供应商 | 先接通一种（如 Qwen/DeepSeek + TTS） |
| 存储 | 上游 SQLite/现有 DB | 扩表：decks, cards, reviews, scenes, devices_mode |
| 家居 | Provider 插件 | 不要把 HA 业务写死在 tutor 代码里 |
